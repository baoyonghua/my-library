# 所有接口 HTTP 一律返回 200，用响应体的 code 判断成败

前后端约定统一的响应包装 `{ code, message, data }`：除了后端不可达（如网关 502）之外，所有接口都返回 HTTP 200，成败由 `code` 判断。200 表示成功，通用错误沿用 HTTP 数字含义（400、401、404、500），违反借阅规则用 409 开头的五位业务码（如 40901 已全部借出）。这是团队统一的接口约定，前端只需在一个拦截器里判断 `code`。不要改回按 HTTP 状态码区分，前端拦截器和测试都依赖这个约定。唯一例外是 PDF 内容接口：成功时直接返回文件，失败时仍返回 JSON 包装。
